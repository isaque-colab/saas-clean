# MEMORY

## Projeto
Fluxo é uma landing page de SaaS para gestão financeira e controle de fluxo de caixa.

## Estado atual
- Estrutura estática pronta para Netlify.
- Tema dark/light com visual minimalista.
- Botão de alternância de tema e formulário de lead.
- Configuração de deploy em `netlify.toml`.

## Arquivos principais
- `index.html`: página principal
- `styles.css`: visual e responsividade
- `script.js`: comportamento interativo
- `netlify.toml`: configuração do Netlify
- `README.md`: instruções de uso

## Como testar localmente
```bash
python -m http.server 8080
```
Acesse `http://localhost:8080`.

## Observações
- O projeto foi mantido como página estática para publicação simples em Netlify.
- A versão completa do SaaS com backend e autenticação pode ser evoluída em seguida.
